# 优惠码页面实现

页面保留 `/admin/promo-codes`，拆为独立组件，通过分页端点读取服务器计算的状态。URL 保存搜索、状态、页码和页大小，搜索/状态/页大小变化回第一页；空越界页提供返回第一页。表格含原九列及状态列，表格内部横向滚动。

新增保留百分比、固定金额（分）、免初装费、每客户一次、仅新客户、循环续费次数和升级专用条件。编辑只提交启停、日期、最大次数、备注及 expected_version，代码、优惠类型和价值不可编辑。日期使用本地时区 datetime-local，提交 RFC3339；空日期显式 null 清除。

POST/PATCH 写前将幂等键和原始 body 保存在当前管理员独立的 sessionStorage。未知失败保留草稿并锁定原请求供人工重试；刷新只显示恢复按钮，不自动发送，也不重新分配键。成功清除请求；明确的版本/幂等409保留草稿，编辑提供“加载最新并替换草稿”，不自动覆盖或重放。其他确定的校验/唯一约束409保留表单并允许修正。浏览器禁用存储时停止写入而非降低防重。

只读用户可读取筛选和列表，无创建/编辑入口；后台仍执行 promos.manage 写权限。取消不发写请求，提交中禁用关闭。未确认提交关闭后仍可恢复原请求。
