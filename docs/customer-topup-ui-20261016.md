# 客户在线充值 UI（2026-10-16）

入口沿用 `/console/account`，从真实 `/balance/topup-options` 展示当前范围、预留与可用额度；金额转换使用整数分。创建只携带金额与设置版本，不接受客户 ID。409 保留输入并刷新规则。

创建请求在发出前按 `/me` 客户 ID 存入当前标签页 sessionStorage，保存原始请求体与幂等键；网络/5xx 结果未知及刷新后均只能以原请求确认。明确业务拒绝后解除请求锁，可修改金额。成功跳转既有账单详情（`?from=topup`），返回账户余额保留上下文。

充值账单不显示余额支付、信用支付或退款；真实支付渠道沿用 `/payment-providers`，过滤模拟渠道。仅 created 可请求取消；accepted 继续原支付或核对结果，不创建新支付；pending_liability 明确显示“已收到款，余额待核对”，不显示充值成功。credited 可返回余额，在线充值流水按 `reference_type=gateway_topup` 链接账单。

已完成隔离真实API与本地易支付协议测试服务器的四尺寸浏览器验收，包含创建、取消、409、未知响应重放、微信通道选择、原支付过期后迟到签名通知、入账追溯、URL恢复及错误恢复，见[集成验收](customer-online-topup-acceptance-20261016.md)。本地协议测试不代表真实商户付款、可信查单或关单；真实外部验证仍待执行。
