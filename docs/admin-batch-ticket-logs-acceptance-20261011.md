## 实现与修复

- 工单状态和工单传递使用真实 Go API，列表返回 `items/total/limit/offset`，写操作具备权限、幂等键、版本冲突和审计保护。
- 默认工单状态不可删除；自定义状态删除前要求浏览器确认。传递规则在真实数据为空时显示空态，不注入静态样例。
- 修复 Chromium 新 `v` 正则模式不接受未转义连字符的问题，将状态标识校验改为 `[a-z][a-z0-9_\\-]{0,63}`。
- 日志页面按短信、站内信、API、邮件分区读取真实后端数据，支持 URL 筛选、分页、权限和安全投影；API 日志不展示原始请求载荷。
- 定时任务日志读取真实 `scheduler_runs`，支持任务、状态、上海日期筛选、分页和 31 日趋势。日志清理保留进行中任务，具有时间保护、确认交互、幂等键和审计记录。
