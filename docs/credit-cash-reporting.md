# 信用付款的现金报表口径

收入、销售收入、仪表盘现金收入均使用两类来源：未使用信用的已支付账单（保持原 paid_at 口径），以及信用还款凭证中的真实金额（按 received_at）。信用消费不算现金；部分还款计实际到账额；完全还款状态不重复计入整张账单金额。全部来源执行当前管理员客户范围。月内账单数按 distinct invoice_id，不将多笔还款当多张账单。

产品收入只将单一发票项目、自动服务/续费账单且服务客户匹配的信用到账归属产品；手工、混合、无服务关联订单不估算分摊，其实际到账仍计入总收入和销售收入。产品报告因此可能低于总现金收入；未做新的产品分摊账本。普通非信用产品报告保持原有口径。

余额流水排名依旧反映余额充值/流水，并未将信用消费当入账，本批不改变它。客户等级的购买指标不转换为现金指标。还款记录属于真实外部到账，后续信用退款须独立处理，不使用整账单 paid/refunded 状态抹除已收到的现金；本批未引入还款现金撤销流程。
