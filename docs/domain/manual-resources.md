# 独立人工资源库存

## 范围与事实来源

人工库存用于登记尚未分配的服务器，并通过已有人工交付流程分配给客户服务。它与 `GET /admin/resources` 的已购服务视图分开；服务视图、供应商订单 JSON、商品可售数量都不能代替独立库存。实现以迁移185、Store事务和[后台API](../admin/api.md#独立人工库存)为准。

库存成本为 CNY 整数分的管理元数据，不生成账本、费用或付款。上游到期日独立保存，不覆盖客户服务的 `next_due_at`，不触发续费或供应商动作。库存可以停用或退役，不提供物理删除接口。

## 库存与占用

库存保存资源标识、名称、IP、加密交付凭据、成本、上游到期日、备注、状态和版本。凭据采用已有交付密钥加密，账号和密码不出现在库存列表、详情、回执和审计中；密码为只写字段。向客户交付时重新使用服务ID封装密文，不能直接复制采用库存ID认证的密文。

`manual_resources` 保存库存；`manual_resource_bindings` 保存服务占用事实及释放记录。数据库保证一个库存最多有一个未释放绑定，一个服务最多有一个未释放绑定。库存的可用/停用/退役状态与是否占用分别判断；不能通过编辑状态绕过占用。

已绑定资源的交付字段不能直接修改，成本、上游期限和备注可按版本修改。客户通过现有服务凭据流程读取交付信息；本批没有新增人工服务自动改密能力，不能通过改库存悄悄改变已交付服务。

## 人工交付绑定

绑定使用现有 `POST /admin/services/{id}/delivery`，不提供绕过交付的裸绑定接口。携带库存ID及库存、服务版本，并引用真实交付任务；库存绑定只适用于人工 `create` 任务且任务为 `waiting_manual`。订单审核、服务状态、客户范围和现有资金/权益围栏继续生效。

事务按照服务、任务、库存的顺序锁定业务行，检查库存可用且未占用，再原子完成绑定、服务开通、交付任务、通知和审计。库存账号密码仅用于写入服务的交付字段，不写入任务结果或审计。相同任务与原请求恢复原结果，不重复绑定或发送开通通知；不同请求不能覆盖成功任务。库存版本或服务版本过期返回冲突，保留草稿并核对当前状态。

没有选择库存的既有手工交付继续兼容。新库存协议不得用于供应商/NOKVM任务、非开通任务、未付款或未审核订单，也不能伪造已经交付的资源。

客户通过已有授权服务凭据接口读取实际交付信息；仅当人工服务存在有效库存绑定并满足原服务状态及归属规则时允许。库存管理接口不新增密码读取旁路。

## 释放与复用

服务终止不会自动将库存变为可用。管理员核实机器已回收后，使用显式释放接口，提交稳定幂等键、库存版本和原因。事务锁定关联服务并确认真实 `terminated`；运行中、暂停或仍待人工终止的服务均拒绝。

释放与已有人工终止流程相互独立，不直接改服务状态，不清空服务历史凭据，不撤销账单或通知。释放只结束占用事实并更新库存版本。相同原请求重放仍按原服务的当前客户范围鉴权，返回原结果，不影响后来形成的新绑定，也不表示资源当前空闲；再次交付前必须读取当前库存及版本。释放后需要新交付意图才能分配给另一服务。停用或退役库存即使已释放，也不能用于新开通。

## 权限与结果恢复

读需要 `resources.view`，管理还需要 `resources.manage`；绑定同时要求原服务管理权限。未分配库存属于全局资源，只对全客户范围管理员开放。已绑定库存的可见性另按服务所属客户范围判断；看不见的资源返回404。写请求等待后重新核对权限、范围和实际会话/API密钥，审计与回执完成后提交前再检查凭据自然过期。

库存创建、修改和释放复用统一 `mutation_operations`，必填稳定 `Idempotency-Key`，编辑及释放还使用对应资源的版本。超时或断网保留原请求体/key重放，不更换版本或key推定失败；重放仍要求当前授权。首次写入、审计及回执同事务提交，任一失败全部回滚。

## 验证与发布

行为测试归现有 `scripts/test-admin-api.mjs --integration`，不新增平行状态机或领域门禁。验收至少覆盖严格输入、权限及客户范围、真实凭据撤销、并发抢同库存、任务重放和异参冲突、审计失败回滚、密文与服务凭据读取、终止前拒绝释放、终止后显式释放及真实184起点升级。

本批严格后台98项（HTTP 89、Store 9）已在任务自有PG18的UTC会话以race串行执行，全部run/pass、零跳过，包含上述库存用例。该结果为隔离数据库行为证据，不能代替库存页面、浏览器或真实机器回收验证。

迁移185只建立独立库存及约束，不从已有服务或供应商JSON推断库存。发布前停旧API、worker和其他writer，成套升级迁移/API/worker；不在新schema混跑旧writer。合成旧数据升级不代表生产恢复或旧二进制降级已验证。库存页面接线、浏览器、真实服务器交付及部署分别验收，API实现不代表这些流程已完成。
