# 流量包管理与订单批次（2026-10-11）

本批覆盖旧版第 10 页 `#/dcim-traffic-log` 与第 70 页 `#/dcim-traffic`，新增迁移 121 的真实流量包目录、适用产品和购买快照。商品价格使用整数分，目录至少 1 分；订单强制绑定服务和唯一账单。

## 已实现

- 后台 `/admin/traffic-products`：分页搜索、启停筛选、新增/编辑/删除、容量/价格/库存、适用产品搜索分页。已有购买历史不可删除。
- 后台 `/admin/traffic-orders` 与详情：真实购买列表、筛选分页、待支付取消、已付款人工交付核验。
- 客户 `/console/services/{id}/traffic`：本人活动/暂停服务可查询适用流量包，购买生成真实独立账单，进入现有账单支付页面。
- 购买锁定目录并占用库存，支付后进入 `waiting_manual`；取消/未交付退款返还库存一次。已核验交付拒绝自动退款，避免假装回收真实资源。
- 所有管理写操作使用权限、事务审计、`expected_version`、幂等键和并发键锁；取消/交付核验持客户范围锁。目录列表总数与记录来自同一读取快照。
