# Public SEO and shareable pages

Set `PUBLIC_ORIGIN` to the customer-facing HTTP(S) origin, for example `https://example.com`. It is used for canonical URLs, Open Graph/Twitter previews, JSON-LD and sitemap links. `WEB_INTERNAL_URL` is a fallback for local deployment; request `Host` headers are never used to build public URLs. `API_INTERNAL_URL` points the Next server to the Go API.

Public pages are `/`, `/products/{id}`, `/news`, `/news/{id}`, `/knowledgebase`, and `/knowledgebase/{id}`. Product detail renders a dedicated configuration page from the anonymous `GET /api/v1/catalog/{id}` response. Catalog cards link to it and omit configuration and purchase-field controls; the detail page preserves the same numeric URL, metadata and visibility rules. Configured amounts are estimates; customer group discounts and coupon totals come from the authenticated cart quote. Purchase values never enter public URLs, metadata or structured data. Articles use cookie-free `GET /api/v1/public-content/{kind}/{id}` for server HTML and metadata. For customer-only knowledge articles, the public preview returns 404 and the page emits generic `noindex` metadata; the existing browser session fetch can still display the article to an authorized customer. Draft, archived, future, hidden-category and inaccessible articles never enter public metadata or the sitemap. Anonymous preview reads do not increment article views.

`/robots.txt` points to `/sitemap.xml`. The sitemap index lists `/sitemaps/{chunk}.xml`, with at most 10,000 dynamic URLs per chunk. Each chunk fetches `/api/v1/public-index` in pages of at most 1,000. The first chunk also includes the root, article list pages, and downloads. The Go API returns JSON only; Next produces escaped XML. Sitemap requests return 503 when the public index is unavailable or its count changes during chunk generation. Concurrent edits that preserve the count can still shift offset pages, so crawlers may need a later crawl to see every new URL. Sitemap and preview requests do not forward browser cookies.

Before publishing, verify the production `PUBLIC_ORIGIN`, API reachability, and the generated `/robots.txt`, `/sitemap.xml`, one chunk, a visible product, a public article, and a private article with and without a customer session.

Authenticated administration, console, cart and account forms emit noindex metadata. The product schema omits offers because the base amount can differ from purchasable configured totals; only anonymous public articles receive Article/NewsArticle schemas. Custom SEO editors, aliases and public image previews remain outside this batch.
