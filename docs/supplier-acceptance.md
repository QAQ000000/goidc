# 上游商品接入验收

本批于2026-10-06开发、2026-10-07发布。开发实例已升级至schema083；供应商服务详情入口为 `/admin/services/{id}`，供应商管理入口为 `/admin/suppliers`。实现提交包括 `1fd0fad`、`777a948`、`6b5cb7b`。

## 已实现

- 供应商注册表、统一 `Adapter`、标准商品/配置/价格/状态及能力声明；第一个provider为 `zjmf_finance_v1`。未来系统在注册表增加适配器，复用本地商品、购物车、订单与交付任务。
- 管理员维护账户，凭据绑定账户加密；目录预览、查看配置、选择固定上游规格和成本上限、导入为下架商品、独立本地售价/上架、只读供应来源。来源、固定规格、账户身份与账期不可修改，改来源须重新导入。
- worker在事务外调用上游；账户持有持久租约，结果不明时阻塞账户后续购买，禁止自动重发。后台登记已交付或明确未执行的核验结果；已存在资源不可换绑。
- CNY整数金额、初装费和配置成本计算；购买前复查上游版本，付款前校验完整账单成本及同资源分项，付款结果须对应原资源。同步商品归属、状态和实际上游到期时间，开通中资源有界延迟同步。
- 隐藏/停用商品、缺失或不支持的付款规则、无效初装费、高级联动/阶梯价格及专用主机名/密码规则明确拒绝；固定规格和单一范围数据盘数量已支持，数量按单价乘算并校验边界。服务详情已接入电源（开机、关机、重启、硬关机、硬重启）、VNC、镜像重装、密码重置、救援系统和退出救援系统；每个动作均有幂等键、权限校验、账户租约和上游结果核验。续费、自动续费、升级、暂停/恢复/终止/自动取消仍未接入真实供应商协议；活跃上游资源须先在上游取消并同步终止后才能本地退款。

## 发布与运行边界

发布前发现原开发环境未配置 `PROVISION_ENCRYPTION_KEY`。确认NOKVM服务、现有服务密文和任务密文均0后生成32字节随机密钥，只写本地 `.env`。现有敏感购买字段使用自己的密钥，未变更；新密钥不进入Git，后续须稳定保存。开发库仍2用户/4商品/2订单/2服务/2账单，供应商账户与绑定均0，验证码 `auth_captcha_enabled=false`。

恢复材料为 `bin/previous/20261006T160850Z-supplier081/`，仅保留schema080 dump、旧API/worker/migrate及移动后的旧Next.js构建，不额外打包一份同样的前端。新增来源数据写入后不能只换回旧worker；应暂停项目服务并一致性恢复数据库、二进制、前端和相应环境。

本次真实联调使用专用上游客户账户，配置真实下游 `PUBLIC_ORIGIN`；当前 `http://localhost:3088` 只适用于本地开发，供应商无法访问该地址。Go 已补齐旧 PHP 使用的 `POST /api/host/sync` 回调，校验 MD5 排序 JSON 签名后更新本地状态、资源信息和加密凭据；同步轮询优先使用 `/host/header`，再回退 `/cart/hostinfo`。美国和香港测试资源仍处于上游 `Pending`，需在可公网访问的回调地址配置完成后再次观察；资源和账单 ID 已保留，不能在状态未知时盲目删除或重试。其他系统适配器、续费/取消/升级、暂停/恢复/终止及高级配置仍待后续实现，整体 PHP 重构未完成。扩展方法与接口约束见 [供应商协议](supplier-protocol.md)。
