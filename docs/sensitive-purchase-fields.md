# 敏感购买字段

商品购买字段可标记为敏感信息。管理员编辑页提供开关，客户填写后通过 AES-256-GCM 保存；购物车、订单、服务和账单接口均不返回明文或密文。敏感字段不会展示在账单上，界面显示为隐藏值。

部署环境需要配置 `PURCHASE_FIELD_ENCRYPTION_KEY`，格式为 64 位十六进制随机密钥，保存在未提交的环境文件中。未配置时禁止启用敏感字段，也拒绝处理敏感购买数据。密钥须随环境备份保留；不能直接更换或删除后继续读取原有数据，密钥轮换需要先实现显式重加密流程。

加密认证数据绑定客户、商品和字段标识。请求只能提交明文；不接受 `enc:` 密文或新增时的 `********`。编辑已有购物车项目时，星号仅保留当前账户该项目对应的既有敏感值。省略购买信息的数量修改也保留原值。相同明文配置使用带密钥的稳定购物车标识，随机加密 nonce 不会产生重复商品项目。

当前仅开放 `purchase` 用途。`admin` 专用字段、`customer` 资料映射以及授权查看明文的操作尚未形成完整业务流程，定义保存返回业务冲突，不写入客户 metadata，也不提供未完成的界面入口。schema079 中相应列保留作后续扩展。旧 PHP 与旧数据仅作参考，没有评论或评价互动。
