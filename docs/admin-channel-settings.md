# 后台接口设置

后台接口设置参考魔方财务的接口目录交互，但实现继续采用编译进 Go 二进制的注册表。数据库只保存渠道实例、启用状态、排序和加密配置。

## 信息架构

`/admin/channels` 是统一入口，顶部按类别切换：支付接口、邮件接口、短信接口、第三方登录。`/admin/payment-settings`、`/admin/smtp-settings` 和 `/admin/sms-settings` 保留为兼容入口，分别打开对应 Tab，避免旧书签失效。

每个类别先显示接口目录，再显示实例状态。目录表保留旧版的管理语义：接口名称、标识、能力、版本、状态和操作。没有实例的编译内置接口显示“未安装/安装”；有实例时显示“启用/已禁用、配置、复制、卸载”。“复制”创建一个停用的数据库实例，不复制密钥，配置后才能启用。

## 配置交互

点击“安装”或“配置”打开配置弹窗。字段由 Go 注册表的 descriptor schema 生成；密钥只显示已配置状态，留空保持原值，清除密钥需要明确勾选。保存使用实例版本号，发生并发修改时由 API 返回版本冲突。邮件和短信已安装实例提供“测试发送”，测试任务绑定当前实例后进入 outbox，由 worker 使用同一组凭据发送。接口实现不会从后台上传，也不会在运行时执行数据库中的代码。

邮件和短信共用接口设置父页面。验证码发送属于通知业务，供应商凭据在短信/邮件接口 Tab 管理，消息模板和发送开关仍由通知管理页面负责。第三方登录 Tab 预留 OAuth 注册表，未注册的接口不会伪装成可用功能。

## 与旧版的字段映射

| 旧版页面 | 新版类别 | 配置来源 |
| --- | --- | --- |
| 支付接口 | 支付接口 | `payment` descriptor 和 `channel_instances` |
| 邮件设置 | 邮件接口 | `mail` descriptor 和 `channel_instances` |
| 短信设置 | 短信接口 | `sms` descriptor 和 `channel_instances`；已迁移智简魔方 `idcsmart`（应用 ID、应用秘钥、SignName） |
| 第三方登录 | 第三方登录 | `oauth` descriptor 和 `channel_instances` |
| 短信发送设置 | 通知管理/消息模板 | 验证码、业务通知开关，不保存供应商密钥 |

旧的单例设置 API 继续作为迁移和兼容边界；新页面不再同时展示两套凭据表单。新增渠道只需增加 Go 适配器和 descriptor，目录和配置表单自动获得相同的安装、启用、配置、复制和卸载交互。
