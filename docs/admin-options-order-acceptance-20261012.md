## 交付及契约

全局组提供组名、描述、关键词/商品筛选、分页、创建编辑、复制组、产品分配与受保护删除。配置编辑支持选择、勾选和数量、周期价与阶梯价表格。130迁移保存全局定义与分配关系，持续原子投影到原商品选项/价格表，保留选项ID并递增商品revision；同一组编辑更新所有已分配商品，原订单配置快照保持不变。商品复制产生独立配置。商品侧对受托组/选项/周期价/阶梯价的写入由数据库触发器拒绝，触发器同时检查移动操作的OLD/NEW归属。

取消分配必须确认，保留为商品独立配置，继续计价，需自行到商品页停用。已分配组禁止删除配置标识、选项标识和更改类型，可停用。重新分配遇到独立配置标识冲突会拒绝，不自动吞并。NOKVM与供应商固定交付商品拒绝分配。全局配置不支持商品专属多级父ID，既有商品层级配置保持兼容。

真实API：`GET/POST /admin/global-configuration-groups`、`GET/PUT/DELETE /admin/global-configuration-groups/{id}`、`POST /admin/global-configuration-groups/copy`、`PUT /admin/global-configuration-groups/{id}/assignments`。读取要求products.view，写入要求products.view/manage及有效会话，事务锁验权限/会话后才能写入或重放，具有版本、商品revision、持久幂等和审计原子性。

131迁移新增订购设置、产品级要求及设置操作回执。`GET/PUT /admin/order-settings` 使用settings.view/manage、expected_version、会话复核、幂等与审计。强制手机绑定以users.phone_verified及非空手机号为准；实名要求最新同类型认证申请已审核通过，且加密资料可解密并通过资料校验，不信任单独的profile状态。有效实名要求为新全局开关、商品开关、原认证设置require_for_purchase三者OR，界面说明来源并链接原设置。入口关闭但客户未满足要求时明确报错，不静默放行。

商品编辑可保存商品级手机/实名要求，原API省略字段时保留旧值，新商品默认false，商品复制继承。后台代客报价/创建、客户结账与优惠报价执行真实准入；成功订单同幂等请求先重放，不因后来规则变化产生重复订单，新请求重新核验。购物车逐项展示资格错误和绑定/认证入口，保留删除等操作，不以整页错误阻断处理。

两页新增权限导航。设置支持取消更改、草稿恢复、版本冲突与错误重载；未知响应保留原请求和幂等键，禁用修改/取消，刷新可恢复重试。全局编辑草稿按账号隔离，离开确认；只读权限不恢复旧草稿覆盖真实数据。
