# 跨商品升级

schema065 增加商品升级专用优惠码；只减免正数本期差额，付款进入升级队列时核销，账单展示原差额与实际优惠。配置/账期变更与续费不使用此优惠，详见 [商品升级优惠](upgrade-promotions.md)。

## 原生范围

schema055 支持原生服务在管理员配置的商品路径上升级或降级。旧系统与旧数据仅作业务参考，没有提取或导入真实旧数据。当前保留服务原来的月、季、年账期；要求服务已启用、未到期、未释放库存、完成历史复核，目标商品上架、购买分类可见、具有启用的相同账期价格，且商品类型和交付模式兼容。需要审核的目标仅支持人工交付。

策略默认没有目标，每条路径单独控制是否允许降低周期金额。后台商品「可配置选项」页维护路径，复制商品同时复制路径；已配置但类型或交付模式不兼容的目标仍在后台显示并允许移除，客户候选列表排除不兼容目标。已有未完成配置变更、开通任务、取消申请或未付款续费阻止新报价及提交。

账期变更、升级优惠码/循环折扣、真实供应商模块、实际网关退款、已开始交付后的撤销或逆向资源恢复仍未完成。

## API

所有路径以 `/api/v1` 开头。

| 方法与路径 | 契约 |
| --- | --- |
| `GET /admin/products/{id}/upgrade-targets` | `products.view`；返回源 revision、已配置 targets 和 candidates（含 compatible） |
| `PUT /admin/products/{id}/upgrade-targets` | `products.view/manage`；提交 expected_revision 和 targets，每项含 product_id、allow_downgrade；最多100条，禁止重复/自身/不兼容目标 |
| `GET /services/{id}/product-upgrade-options` | 本人服务；返回 source_revision 与可选目标的价格/配置目录 |
| `POST /services/{id}/product-quotes` | 本人服务；提交 target_product_id、target_revision、expected_revision、expected_version、option_ids、option_quantities |
| `POST /services/{id}/configuration-changes` | 本人提交 quote_id 与 Idempotency-Key，沿用配置变更账单/状态机 |
| `DELETE /services/{id}/configuration-changes/{change_id}` | 本人取消报价或未付款变更，取消对应账单并返还预留库存 |

付款、人工交付和失败重试沿用 [服务配置变更](service-configuration-changes.md) 的接口与权限。服务详情变更历史区分 configuration/product，并返回源/目标商品ID、目标名称/版本快照。客户只能访问本人服务；只读管理员可以查看策略和服务历史，写操作返回403。

## 计价和合同

目标周期价 = 目标商品相同账期基础价 + 目标有效配置的周期金额。配置共用购买校验，支持数量、阶梯、多级分支和已实现的联动约束，不允许隐藏选项；不要求目标组开放「同商品配置变更」。目标商品或配置的初装费均不收取。

新旧周期价之差按原到期时间和剩余日历账期折算，采用整数分和对称四舍五入。正差额生成应付，负差额生成零金额账单及待返还余额；零金额账单仍需客户确认付款，余额仅在交付成功时返还一次。每条降级路径以最终周期金额是否降低判断，和同商品配置变更逐组限制不同。

报价10分钟有效，绑定源商品 revision、目标 revision、服务 version 和到期时间。提交重新检查可用性和版本；提交后按报价合同交付，目录改价不改变已生成的应收。付款只排队，不切换服务商品。

交付完成在同一事务切换服务商品ID/名称、有效配置和周期价，增加服务版本，恢复目标服务导航显示偏好。原订单/订单项目/下单配置快照保持原样，后续续费使用新服务周期价；服务资料和分组按当前商品读取。现有上游标识沿用，管理员须核验实际资源；模拟交付仅证明本地业务状态。

## 库存与事务

提交对有限目标库存预留一件，与新购使用同一商品行锁；报价不占库存。未付款取消、交付任务尚未领取时的余额退款原子释放预留，重复调用不重复返还。人工/模拟交付成功后，归还源商品有限库存，目标预留转为服务占用。已开始交付不能直接退款。

服务终止成功归还服务当前商品的有限库存，使用 inventory_released 防重；退款后的终止、终止后的原订单退款均不能再次返还。人工终止等待核验时不提前释放。失败交付保留目标预留，沿用管理员失败任务重试。

服务/账单/商品行锁、目录共享锁、幂等键及待处理变更唯一索引序列化操作。纯余额锁使用 `FOR NO KEY UPDATE`，与用户外键引用兼容且仍串行化余额写入。审计失败回滚库存、账单、服务合同及余额；降级交付先锁客户余额再锁服务。
