## 协议兼容修正

对照 `/www/wwwroot/zjmf-manger-decoded/public/plugins/sms/idcsmart/IdcsmartPlugin.php`：发送到国内网关时去掉本地 E.164 号码的 `+86` 前缀；响应兼容开头 UTF-8 BOM，继续接受数字或字符串 `200`。响应超过 64 KiB、无效 JSON、尾随非 JSON 数据以及业务 `405` 均不得标记成功。上游响应正文不直接回显给客户。

BOM 处理属于旧协议兼容修正；第二次实际返回没有 BOM，第一条未捕获响应，因此不能归因为 BOM。第一次用户收件也说明不能将空 `vars` 武断认定为发送失败原因。
