# 旧下载资料迁移

## 范围

迁移044为公共分类、公共文件、产品关联和客户专属文件增加旧身份；产品关联增加稳定内部 ID，原下载/产品复合主键保留。`legacy_snapshot_manifests` 记录完整源实体集合，包括空实体。当前只读快照从10类扩展到14类；仍不是全站切换工具。

| 旧表 | 目标与转换 |
| --- | --- |
| downloadcats | download_categories；转换上级 ID，保留隐藏、排序、说明、创建/更新时间，多层目录按依赖顺序导入 |
| downloads | downloads；保留标题、说明、隐藏、次数、时间；clientsonly 为登录范围，productdownload 为产品范围且优先于登录标记 |
| product_downloads | download_products；转换文件/产品 ID、保留源身份和原字段归档 |
| userdownloads | customer_files；转换客户 ID、保留名称/备注/时间与字节，旧 adminid 归档并写审计 |

公共本地文件来自 `public/upload/support/旧location`；客户文件来自 `public/upload/clients/旧uid/旧url`。显示文件名优先使用 locationname/downame；缺省时使用存储名中第一个 `^` 后的部分或完整存储名。remote 文件按旧读取实现使用 **locationname** 作为 HTTP/HTTPS 链接，不抓取链接内容。

旧管理员尚未迁移，因此必须显式指定目标中启用的超级管理员作为导入负责人；不冒用旧 adminid。公共 author_id 和私有 uploader_id 指向该目标管理员。客户归属始终由旧客户映射决定。

## 操作契约

连接凭据从本机环境注入；下面不包含实际 DSN。第一次 apply 使用以 `_test` 结尾的独立数据库并核对数据。

```bash
# LEGACY_MYSQL_DSN 已安全注入；dry_run 不连接目标 PG
go run ./cmd/legacy-import --legacy-upload-root /path/to/legacy/public/upload

# DATABASE_URL 指向隔离演练目标，TARGET_FILE_ADMIN_ID 是已创建的目标超级管理员 ID
go run ./cmd/migrate
go run ./cmd/legacy-import --mode apply \
  --legacy-upload-root /path/to/legacy/public/upload \
  --file-author-id "$TARGET_FILE_ADMIN_ID"
```

也可通过 `LEGACY_UPLOAD_ROOT` 配置目录。无本地记录时不要求目录；无任何文件记录时不要求负责人。dry_run 验证源引用及实际字节，apply 另行验证目标 schema、负责人、源归档和映射。

Linux文件读取使用目录文件描述符及 O_NOFOLLOW，拒绝 support、clients、客户目录或文件的符号链接。存储名和显示名只接受单个文件名，拒绝越界、控制字符、非普通文件、空文件和超过50 MiB的文件。MIME/签名与现有上传共用白名单：文本、VCF、PNG/JPEG/GIF、PDF、ZIP/常见办公ZIP格式、RAR、旧办公OLE、RTF。其他格式需另外设计适配，不能只改扩展名强行导入。

先逐文件读取并计算 SHA-256/大小/MIME/显示名，指纹进入源归档；新增目标时再次读取并核对 SHA，拒绝预检后字节变化。归档保存原字段和指纹，不保存字节或操作员配置的本地绝对根目录。目标字节保存在PG bytea。

缺失父类、循环、客户/产品/文件缺失、重复产品对、无关联的产品限制、非法时间/标记/路径/字节均拒绝整批。apply 中业务、映射、归档、快照清单和审计共用事务；失败保留独立失败运行记录。源预检失败发生在运行记录创建之前。

## 重跑与权限

相同源快照重跑不覆盖迁移后文件标题、字节、权限、客户转移、目录移动、次数或版本。缺映射但目标旧身份及归档仍可验证时恢复映射。源字节或记录增删改动、目标被删除、映射失效均停止并要求复核。

修改文件时保留未变产品关联的稳定 ID。管理员删除关联后重跑会拒绝失效目标，**不会补回被移除的授权**；这是需要复核的情况，不是自动增量同步。换 source 重复导入不属于恢复方式。

旧工具缺少14实体快照清单时拒绝原地补导入，须新隔离目标重新演练。不能以空表为由忽略快照契约变化。

导入文件即时沿用中央授权：公开/登录/有效关联产品、下载开关、祖先隐藏、客户本人所有权和管理员销售范围。迁移服务仍待复核，因此仅将 status 改 active 不会获得产品限制下载权限。
