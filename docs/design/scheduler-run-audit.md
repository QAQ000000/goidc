# 调度执行历史实现与边界

迁移 104 新增 scheduler_runs，迁移 105 扩展固定任务枚举，记录数据库开始与结束时间、耗时、状态、处理数及固定安全错误码。worker 实际执行佣金结算、服务到期通知入队、账单通知入队、供应商同步入队、自动支付查单、逾期暂停入队和自动续费处理时，通过 RunScheduled 写入真实调用记录；未回填历史。通知发送和服务外部动作尚未接入。

/api/v1/admin/logs/jobs 提供 task/status/from/to 分页过滤；/trend 提供近31天上海时间日汇总。系统执行历史仅 super_admin 可读，即使拥有 jobs.view 的普通管理员也被拒绝，避免全局任务统计泄露。

审计开始或结束写入失败输出固定 audit_write_failed 日志，业务仍只执行一次，不因审计故障重试。取消执行使用独立有期限上下文保存 interrupted；进程被强制终止可能留下 running，界面标记结束未确认，不将其当成功或自动重试。当前不自动标记历史 running 为 interrupted，避免并行 worker 误判。记录不含原始错误、payload、用户名、IP 或客户数据。数据库角色仍可更新记录，本实现不是防篡改存储。
