# PHP 替换准备度与路线图

更新时间：2026-10-07

这份文档把“能编译、隔离测试通过”和“可以替换旧 PHP 生产站点”分开。当前项目仍处于重构阶段，不能切换旧站点，也没有声称生产等价。

## 当前基线

- 旧系统静态清单：`docs/generated/legacy-inventory.json`，1352 条路由调用、184 张表。
- 当前 Go 路由：由 `scripts/route-coverage.mjs` 从 `internal/httpapi/server.go` 生成覆盖索引；方法和路径完全相同时只记为候选，不代表行为兼容。
- 覆盖索引：`docs/generated/route-coverage.json`。每条记录仍需核对处理器行为、认证/权限、状态机和 Next 页面契约。
- 验收边界：隔离 PG18、浏览器和 worker 回归只证明对应批次；真实支付、真实上游和正式切换仍需独立证据。
- 运行边界：Go 仅提供 API，Next.js 负责页面；验证码保持关闭；不开发评论、评价和其他社交互动。

## P0：替换前必须完成

| 领域 | 当前状态 | 完成门槛 |
| --- | --- | --- |
| 真实支付 | 有 mock 与易支付 MD5，真实商户未验收 | 至少一个真实测试商户完成支付、异步通知、主动查单、可信关单边界、原路退款；未知结果必须人工核验；信用额有明确拒绝或完整实现 |
| 上游供应商 | 已有 provider-neutral 接口和魔方财务适配器，真实账户未验收 | 魔方财务真实测试账户完成目录、成本、采购、同步和异常核验；续费/取消/升级/复杂配置要么实现并验收，要么在产品和 API 中明确拒绝 |
| NOKVM | 协议和模拟夹具已覆盖，真实资源未验收 | 专用测试资源完成开通、状态同步、电源、凭据、重装、快照/网络操作；未知结果、人工核验和回滚证据齐全 |
| 旧接口兼容 | Go 约 300 个注册路由，旧系统 1352 条调用 | 逐条完成 `route-coverage.json` 的行为、权限、状态和页面/API 审查；确定 `/v1`、动态后台路由和 OpenAPI 的兼容策略 |
| 切换与回滚 | 没有正式数据切换、压测和回滚演练 | 只读预检、正式备份恢复、负载基线、灰度/双运行、可验证回滚和停机窗口 runbook 全部演练 |

## P1：核心运营闭环

- 短信、实名、OAuth 和联系人独立登录：先定义供应商接口、凭据保管、失败/重试和隐私审计，再做真实沙箱验收。
- 发票与税务：保留当前发票申请和文件模型；接入真实税务服务前不得把 PDF/XML 文件检查写成税务开具成功。
- 计划任务、通知投递和邮件：明确 worker 任务的幂等键、重试上限、死信/人工处理和可观测指标。
- 插件、返佣、提现：与商品、账单、余额流水和权限模型分开设计，避免把资金操作放入通用插件回调。

## P2：非阻断外围能力

- 备份升级的自动化编排、更多历史数据迁移、别名路由和低频后台页面。
- 其他上游系统适配器：复用 `internal/supplier` 的注册表和标准模型，每个适配器单独提供协议、凭据、限流、回放和真实沙箱证据。

## 批次完成定义

每个领域完成前必须同时具备：

1. API、页面和权限契约已记录，包含成功、空、错误、冲突、撤权和移动端状态。
2. 隔离 PG18 测试通过，涉及并发或 worker 的批次追加 race 和恢复测试。
3. 浏览器流程覆盖真实 Next 代理；没有浏览器或真实外部凭据的部分标为“未验证”，不得写成 PASS。
4. 发布前保留迁移、二进制、环境和数据库恢复材料；新增敏感数据后只能做一致性回滚。
5. 文档更新当前 schema、BUILD_ID、服务健康检查和明确的未完成边界。

## 当前执行顺序

1. 生成并逐模块审查 `route-coverage.json`，先锁定高价值客户、订单、账单、服务和供应商路径。
2. 建立真实集成前置条件清单，取得测试商户、魔方财务账户、NOKVM 资源以及短信/实名/税务沙箱凭据后再做联调。
3. 先完成真实供应商/NOKVM/支付验收，再做兼容映射和切换演练；没有这些证据不进入生产替换评审。
4. 所有 Go 命令优先使用 `scripts/go.sh`，用 `scripts/check-go-toolchain.sh` 检查版本和 GOROOT，避免本地 Go 与 `/usr/local/btgo` 混用。

## 明确不纳入本阶段

- 不修改 `/www/wwwroot/zjmf-manger-decoded-副本`。
- 旧数据提取仅作参考，除非某个迁移批次明确需要只读演练。
- 不开发评论、评价或社交互动。
