## 基线与结论

源码基线 `3cf94d9`，目标旧项目 `/www/wwwroot/zjmf-manger-decoded`。由三个 `gpt-6.1-sol` 子代理分别审计核心业务、页面覆盖、集成与运维，主代理交叉核对关键结论。

后续进展（2026-10-16）：以下保留审计基线；[阶段一](core-replacement-stage1-acceptance-20261016.md) 已修复 G05 候选扫描与 API 日志权限、修正3项台账范围；[优惠码批次](promo-code-acceptance-20261016.md) 已关闭#36主页面缺口，当前登记为45完成/60部分完成。[合同设置模板本批](contract-settings-restoration-acceptance-20261016.md)已补检索/分页、冲突及旧请求恢复，#38完整合同政策仍部分。历史截图异常已明确登记，尚未补齐有效替代证据；其余业务缺口不因此关闭。

后续核心经营增量：G03已关闭普通人工账单的外部退款登记首增量，复杂业务冲正及可信关单仍待补；客户在线充值已实现并通过隔离资金/四尺寸验收；G06三种公开工单事件通知已集成并完成专项与浏览器验证，邮件payload补正的最终全量已通过。详见[当前目标](core-replacement-goal-20261016.md)及[工单通知验收](ticket-notification-acceptance-20261016.md)。G07和供应商客户自助入口首增量已通过本地集成/双worker进程/四尺寸，见[供应商验收](supplier-customer-acceptance-20261016.md)；真实云主机动作仍待外部证明。下方表格保留审计基线，不再把这些首增量解释成当前完全缺失；未关闭的外部收件、上线和完整旧版差异继续有效。

**当前具备核心交易与运营框架，但尚不满足直接停用旧站、完整接管生产的条件。** 剩余工作应区分：现有功能的正确性修复、缺失业务闭环、真实外部验收、正式发布，以及旧版外围能力。不能继续使用“实名、信用额、返佣提现、供应商续费完全没有”的历史判断。

本轮为静态源码与既有验收证据审计；只读探针确认 API `/healthz`、`/readyz` 均 HTTP 200，三个 systemd 服务 active。这不证明现场运行的是当前源码。未运行浏览器、全量测试、写业务库或真实第三方操作，未部署、未提交此文档。

## 页面与证据质量

1. 105 项台账至少存在三项完成范围不足：#36 优惠码、#38 合同设置、#103 商品编辑。建议分别记录“页面可用 / 旧能力差异 / 浏览器状态验收 / 生产验收”，避免单一完成标记。
2. API 日志菜单要求 `notifications.view`，后端要求 `audit.view`，会出现有审计权限却无菜单、只有通知权限却进入后 403；本轮没有发现因此越权读数据。见 [菜单](../web/src/lib/admin-navigation.ts:71)、[后端权限](../internal/httpapi/admin_permissions.go:103)。
3. 浏览器索引 157 张截图均存在；149 条有摘要，143 匹配、6 不匹配，8 未填摘要。失配集中于 jobs/logs-jobs 的复用截图路径，应补不可变证据；不能据此判断当前页面必然失败。
4. 索引 PASS 主要证明指定加载/布局检查，不能等同 105 页所有保存、取消、权限、409、错误恢复、危险操作都通过。见 [证据索引](admin-restore-browser-evidence.json)。

## 旧数据与上线范围

- 用户已明确旧数据仅作参考，因此空库新站不应被“247 条历史 issue、必须开发增量导入、旧密码迁移”阻断。
- 如果要接管存量客户、余额、账单和在运服务，则必须单列迁移项目：最新快照、金额/资源复核、旧密码或可验证找回方案、冻结窗口、最终导入及回滚。10-14 的 247 条是当时快照，不是本轮源库实时结果。
- 当前 importer 拒绝源漂移，没有增量导入实现。停机时间允许时可评估最终冻结全量导入；若必须低停机增量接管，则需要真正的增量工具。不能绕过 source changed 保护。
- 编译期 Go 模块注册、类型化工厂、加密实例和动态配置表单已有基础。PHP 上传插件、运行时 `.so`、评论/评价不属于待补范围；系统信息/数据库状态采用 Go/PG 语义属于设计选择。

## 推荐实施批次

按依赖顺序拆成八个可验收批次；这是工作划分，不是工期承诺。每批需源码审查、隔离 PG18 回归及对应浏览器/真实链路证据。

1. 正确性与证据修复：逾期暂停扫描、菜单权限、台账范围与截图摘要。
2. 支付异常：可信查单、关单核验/安全解锁、外部退款到账登记和关联冲正。
3. 客户资金：自助在线充值；信用客户门户按业务范围接入。
4. 工单通知：客户创建/回复、客服回复、事件模板与投递状态。
5. 供应商生产链路：实际云主机动作、客户自助运维、常驻自动续费验收。
6. 页面深度还原：按业务域逐批关闭 58 项部分完成和至少 3 项范围收窄条目。
7. 发布终验：一致构建/迁移、公网支付、短信（启用时）、任务恢复与负载、切流回滚。
8. 范围扩展：联系人子账户、OAuth、第三方实名、完整合同/税务/多币/DCIM及旧接口消费者兼容；按现网依赖调整优先级。

历史准备度文档与部分批次文档包含已过时描述；本报告仅纠正当前判断，不覆盖或抹去当时真实验收边界。
