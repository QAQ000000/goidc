## 实现

商品的非编辑式自动主机名/密码规则可用时，适配器按字符集合、长度、主机名前缀生成随机凭据；需要客户填写或规则不可识别时仍拒绝。规则进入商品 revision，库存变化不影响 revision，原来无规则商品的 revision 保持兼容。

创建响应兼容顶层或 data 中的标量/单元素数组 ID，拒绝多个资源或冲突 ID。响应只返回账单号时，从该账单的唯一 host 项恢复资源号；必须确认所有允许的账单项均属于同一资源、币种为 CNY、成本不超过绑定上限，且付款前资源对应指定商品。

上游未付账单只发送一次 apply_credit，使用 enough=1，禁止部分余额付款和信用额度回退。支付响应缺少 hostid、只有受理状态或传输失败时，读取同一账单确认 Paid、金额与资源不变，不能靠响应状态直接认定付款；无法确认时保持原任务待核验和账户锁，不再发送付款或重下单。已付账单不再次付款。

付款确认后读取资源，Active 才变成本地 active，Pending 则保持 provisioning 并由后续 sync 任务推进。账单/资源无法识别、归属或成本冲突、写请求结果不明及 worker 已发送请求后崩溃仍保留人工核验；本轮未实现安全自动重发购买/付款。
